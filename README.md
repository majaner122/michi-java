# Michi en Java

Juego de consola para dos personas en un tablero de 3 × 3. Cada jugador usa una ficha (1 o 2) e indica la fila y la columna con números del 0 al 2. El objetivo es alinear tres fichas en una fila, columna o diagonal.

## Cómo jugar en NetBeans

1. Instala un JDK 24 o superior y configúralo en NetBeans.
2. Descarga o clona el repositorio. Si descargas el ZIP, descomprímelo.
3. Abre en NetBeans la carpeta que contiene el archivo **build.xml**.
4. Ejecuta el proyecto con **Run Project** y sigue las indicaciones de la consola.
